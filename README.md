# 🔐 Login & Registration Page

A modern and responsive **Login & Registration Page** built using **HTML, CSS, and JavaScript**. This project features a clean authentication interface with smooth transitions, intuitive form layouts, and a mobile-friendly design, making it ideal as a front-end authentication template.

## 🌐 Live Demo

👉 https://maheshwar029.github.io/login-registration_page/

---

## ✨ Features

- 🔑 User Login Form
- 📝 User Registration Form
- 🔄 Smooth form switching animation
- 📱 Fully responsive design
- 🎨 Modern and clean UI
- ⚡ Fast and lightweight
- 🖥️ Cross-browser compatibility
- 🛠️ Easy to customize

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/maheshwar029/login-registration_page.git
```

Navigate to the project directory:

```bash
cd login-registration_page
```

Open the `index.html` file in your browser, or run it using a local development server.
